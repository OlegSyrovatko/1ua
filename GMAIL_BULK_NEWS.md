# Пам'ятка: нічна розсилка новин на gmail.com

Контекст: 26.07.2026 Gmail почав відхиляти листи через низьку репутацію
відправника (`550-5.7.1 low reputation`). Причина — нічна масова розсилка
новин (`obl_future_news1..25`) на застарілу базу gmail-адрес. З 26.07 нічна
розсилка на gmail.com була повністю заблокована в `SendEmailJob.php`.
З 30.08.2026 вона відновлюється поступово й автоматично.

## Одна команда для перевірки

```
php artisan gmail_bulk_report --days=7      # за тиждень
php artisan gmail_bulk_report --days=30     # за місяць
```

Дивитись на:
- **"репутаційних відмов (550-5.7.1)"** — має бути **0**. Це єдина цифра, що
  реально сигналізує про проблему з репутацією.
- "інших відмов (unknown user/mailbox full)" — це нормально, не привід
  хвилюватись, воно й мало зростати з часом (старі адреси).
- перший рядок звіту — поточний **активний %** для старих (dormant)
  gmail-адрес і коли його востаннє міняв автотюнер.

## Історія рішень автотюнера

```
grep "GMAIL_BULK_AUTOTUNE" storage/logs/laravel.log | tail -30
```

Кожен рядок — це один день: `X% -> Y% (причина)`. Тут видно весь шлях
підняття/відкату з часом.

## Як це працює саме собою (нічого робити не треба)

Щодня о 9:00 (`app/Console/Kernel.php`, `gmail_bulk_autotune`):
- чисто (0 репутаційних відмов на @gmail.com за останні 3 дні) → **+3%**,
  не частіше ніж раз на 2 дні, до стелі **25%**;
- будь-яка репутаційна відмова → **миттєвий відкат удвічі**, без очікувань.

Стеля 25% — свідомо низька. Якщо через місяць-два все чисто і захочете
йти вище — підняти `GMAIL_BULK_NEWS_CEILING` в `.env` (наприклад до 50).
Автотюнер сам далі не піде, поки ви не підніміте стелю руками.

## Якщо щось виглядає погано (ручний override)

Одразу обнулити % (без очікування наступного автотюну):

```
php artisan tinker --execute="
Illuminate\Support\Facades\Cache::store('database')->forever(
    App\Services\MailDeliveryService::GMAIL_DORMANT_PERCENT_KEY, 0
);
"
```

## Якщо cron взагалі не спрацьовує (перевірка живучості)

```
crontab -l -u site_user | grep artisan     # має бути schedule:run щохвилини
grep "GMAIL_BULK_AUTOTUNE" storage/logs/laravel.log | tail -1   # має бути вчора/сьогодні ~09:00
```

## Довгостроковий орієнтир

Коли % впреться в стелю (25%) і буде стабільно чисто кілька тижнів —
це сигнал, що можна:
1. підняти `GMAIL_BULK_NEWS_CEILING`,
2. або переглянути `GMAIL_BULK_NEWS_ACTIVE_DAYS` (зараз 180 — можна
   поступово знижувати поріг "активності", щоб залучати більше
   старих, але реальних підписників).

Немає жорсткого дедлайну — рухатись тільки коли `gmail_bulk_report`
стабільно показує 0 репутаційних відмов.
